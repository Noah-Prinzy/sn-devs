### SmoothUI — https://smoothui.dev
- **What it is:** Free, open-source collection of **228 animated primitives and components** for React (site claims 228; GitHub README and older sources cite 75–198+, catalog grows continuously). Four tiers of assets: **Primitives** (owned headless + Motion: button, dialog, checkbox…), **Components** (motion-ready drop-ins), **Blocks** (page sections: heroes, pricing, FAQs, footers, logo clouds, stats, team sections), and **Templates** (full starter pages). By Eduardo Calvo (educalvolpz), part of the Vercel Open Source Software Program; ~1k GitHub stars.
- **Design language:** "Made to move" — cohesive contemporary design system with a mascot ("Smoothy"); spring-physics motion as a first-class design token; light/dark mode out of the box; unified Tailwind token spine; calm, polished product-UI aesthetic rather than flashy demo effects.
- **Component catalog highlights:** SiriOrb (animated orb), DynamicIsland (iOS-style), AI Prompt Input, Infinite Slider, RichPopover, ScrollableCardStack, FloatInput, FluidMorph, MatrixCard, CursorFollow, ScrambleHover, WaveText, TypewriterText, ExpandableCards; block families for Hero, Pricing, Testimonial, FAQ, Footer, Logo cloud, Stats, Team.
- **Install / integration:** shadcn-registry one-liner: `npx shadcn@latest add @smoothui/siri-orb`; own CLI `npx smoothui-cli add siri-orb`; copy-paste source. **AI-native:** shadcn MCP server works out of the box, plus a public no-auth search/suggest/source API with OpenAPI spec, `llms.txt`, and machine-readable JSON catalog for RAG pipelines.
- **Stack & dependencies:** React 19 (ref-as-prop, no forwardRef), Motion 12 (née Framer Motion) + GSAP, Tailwind CSS v4, TypeScript, Server Components. Every component is `prefers-reduced-motion` aware.
- **Skills to steal:** (1) Reduced-motion as a non-negotiable default — animations collapse to instant state changes; (2) the four-tier asset ladder (primitive → component → block → template) as a library-structure pattern; (3) "motion you can read in the source" — ship source, not a package, so nothing is hidden; (4) agent-first distribution (MCP + public API + llms.txt) — the most complete AI integration of any library in this research; (5) "UI Craft" companion tool (anti-slop detection, scored quality gate, convergence loop for agent-built UI) — a model for gating AI-generated UI quality.

### cult-ui — https://cult-ui.com
- **What it is:** Free, open-source (MIT) library of **154 animated components** (58 recently added) that extends shadcn/ui — "Shadcn, expanded." By Nolly Studio (@nolansym), ~7k GitHub stars. Monetized via companion product **AI SDK Agents** (150+ paid full-stack blocks for the Vercel AI SDK, one-time purchase) which funds the free library.
- **Design language:** shadcn-native but more experimental/product-flavored: dark-first showcase, device mockups, physical/material metaphors (fluted glass, folded cards, shadow cards), AI-era interfaces (agent cards, collab toolbars, kanban boards). Light+dark previews for every component.
- **Component catalog highlights:** Globe (3D), Kanban board, Fluted glass, Mac screen, Analytics chart, Folded card, Merging bubbles, Circuit board, Security checkpoint, Apple Watch Ultra / iPhone 17 Pro / Keyboard / Pro Display XDR device mockups, Collab toolbar, Shadow card, Agent Suggest Card Stack, Shift card (hover-reveal detail), Screen Capture.
- **Install / integration:** shadcn registry install (one-line per component) into any shadcn/ui project; copy-paste source; docs include an MCP server page; theming docs for design tokens.
- **Stack & dependencies:** React + Tailwind CSS + shadcn/ui primitives; animated components in the shadcn source-ownership model; MIT licensed.
- **Skills to steal:** (1) Device-mockup components (Mac screen, iPhone, Apple Watch) as marketing assets — reusable "screenshot framing" kit; (2) pairing a free MIT component library with a paid vertical product (AI SDK agents) as a sustainable funding model; (3) "every component on this page is live in its docs" — interactive docs as marketing; (4) AI-agent-flavored component vocabulary (agent suggest stacks, tool-call chips, collab toolbars) — a naming/pattern space for AI product UI.

### HyperUI — https://hyperui.dev
- **What it is:** Free open-source (MIT) collection of **Tailwind CSS components** by Mark Mead — copy-paste **HTML + Tailwind markup**, no framework lock-in, no JS required for most components. Organized into **Application**, **Marketing**, **Neobrutalism**, **Templates**, plus browser-based **Tools** (dark-mode variant generator, typography-scale mapper) and **HyperUX** (js.hyperui.dev, JS-enhanced variants).
- **Design language:** Clean, utilitarian, production-Tailwind aesthetic; three distinct style families — default, application-UI, and a full **Neobrutalism** set (hard borders, offset shadows, flat saturated colors). Every category ships multiple complete variants (e.g., 10 accordions, 10 badges, 10 breadcrumbs).
- **Component catalog highlights:** Application: accordions (10), badges (10), breadcrumbs (10), button groups (10), charts (22), checkboxes, details lists, dividers (12), dropdowns. Marketing: announcements (12), banners, blog cards (13), buttons, cards, carts, contact forms, CTAs, empty content (10). Neobrutalism: accordions, alerts, badges, buttons (10), cards, checkboxes, inputs, progress bars, selects — all full variant sets.
- **Install / integration:** Pure copy-paste of HTML/Tailwind markup — nothing to install; works in plain HTML, React, Vue, or any Tailwind setup. Responsive by default.
- **Stack & dependencies:** Tailwind CSS only (HTML markup); some interactive pieces need small JS or the HyperUX variants. MIT license.
- **Skills to steal:** (1) The "many complete variants per category" doc pattern — show 6–22 working versions, not one abstraction; (2) in-browser dark-mode variant generator and typography-scale tools — utility tools that build audience; (3) full neobrutalism family as a complete, coherent style kit; (4) framework-agnostic markup discipline (Tailwind classes that survive React/Vue/HTML unmodified); (5) empty-content states as a first-class marketing/application category (usually forgotten).

### Preline — https://preline.co
- **What it is:** Large open-source Tailwind CSS UI library by Preline Labs: **640+ free components, 972 blocks (189 free / 783 Pro), 22 templates (5 free), 27 headless plugins, 100 animated icons, free Figma design system**. Positioned as a free "Tailwind UI (Tailwind Plus) alternative." Very strong AI-tooling push (Preline v5.0: MCP, AI Prompts, Agent Skills).
- **Design language:** Enterprise-polished marketing + application aesthetic; accessibility-aware; theming system with named themes (Harvest, Retro, Ocean, Autumn Moon, Bubblegum, Cashmere…) × extensive branding-color palette × sans/serif/mono fonts × dark mode — "unlimited custom themes" applied consistently across every block.
- **Component catalog highlights:** Advanced Select (40 variants!), Dropdown (22), Tables (19), Buttons (16), Badge (14), Accordion, Avatar Group, Timeline, Sidebar (10), Switch/Toggle (10), Datepicker, Marquee; blocks for Chart Compositions, Dashboard Headers, KPI Cards (17), Product Review Sections, Project Tables, Hero Sections (15), Create & Edit Form Modals (10), Checkout Flow Pages (8), Advanced Forms, Application Navbars; templates: Admin Dashboard (31 pages), Storefront (39 pages), SaaS Startup, Ecommerce Admin, Digital Agency.
- **Install / integration:** `npm i preline`, Tailwind v4 `@source` + `variants.css` wiring, script tag for behaviors. Framework guides for 25+ stacks (React, Vue, Next, Nuxt, Angular, Astro, Svelte, Solid, Qwik, Remix, Laravel, Hugo, Rails, Django, Flask, Blazor, …). **AI layer:** Preline MCP (connect agents to components/blocks/docs — free through Jan 1 2027 with Pro), copy-paste block-specific AI Prompts, portable Agent Skills for IDE/CLI.
- **Stack & dependencies:** HTML + Tailwind CSS + its own accessible headless JS plugins (no React/Vue source shipped — patterns are adapted by hand). License: free tier under **MIT + Preline UI Fair Use** (attribution-preserving redistribution allowed); **Pro $249** (single dev, lifetime), **Team $459** (15 devs); Pro forbidden in open-source projects, reselling, or derivative themes/generators.
- **Skills to steal:** (1) The theming matrix (named themes × brand palettes × fonts × dark mode) applied across an entire catalog — the gold standard for "theme once, restyle everything"; (2) animated icons as pure SVG + CSS keyframes with `currentColor`, zero JavaScript — motion without dependency weight; (3) three-pronged AI strategy (MCP + per-block AI Prompts + portable Agent Skills) — a complete blueprint for agent-friendly docs; (4) enormous component-variant depth in form controls (Advanced Select ×40); (5) free Figma design system with tokens/variants as the design-dev bridge.

### PrebuiltUI — https://prebuiltui.com
- **What it is:** Growing library of **435+ copy-paste Tailwind CSS components** plus free & premium React/Next.js/HTML templates (Maison e-commerce, Buildify AI-agents SaaS, DentCare, Forged gym, SaaSly, Launchify, etc.), a Logos section, and a Gradient Generator tool. Components free; templates mix free and paid (promo: $5, regular $29).
- **Design language:** Modern, clean SaaS/landing aesthetic with per-template theming (orange AI theme, blue clinic, dark-luxury gym); Framer Motion animations in the React templates; mobile-responsive by default.
- **Component catalog highlights:** About, Alert, Avatar, Badge, Banner, Blog Sections, Breadcrumbs, Buttons, Card, Carousel Sections, Checkbox, Cookie Policy (consent UI!), Call to Action, Dropdown Menu, E-commerce, FAQ Sections; template topics: e-commerce, SaaS landing, restaurant, healthcare, architecture, AI startup, portfolio, agency, dashboard UI.
- **Install / integration:** Copy component code from the components page and paste into HTML/React/Vue files — no package, no registry. Templates delivered in Next.js, React, and HTML variants. Has `llms.txt` for agents.
- **Stack & dependencies:** Tailwind CSS required; most components pure HTML+Tailwind (no JS); interactive ones need JS in React or vanilla. React/Next/Vue/static-HTML compatible.
- **Skills to steal:** (1) Cookie-policy/consent components as a first-class catalog category (rare and practical); (2) one template shipped in three stack variants (Next.js + React + HTML) — maximum reach from one design; (3) niche vertical template strategy (dental clinic, gym, bakery, cafe, barbershop, interior design) — pattern for targeting long-tail audiences; (4) gradient generator + logo pack as sticky side-tools.

### Animmaster Lib — https://animmasterlib.dev
- **What it is:** A **paid, one-time-purchase pack of 300 "PRO-level" animated UI components** — rebuilt-with-clean-code recreations of effects from top-tier (Awwwards-style) websites. Indie product by "Animmaster" (Instagram/Telegram), ~2,400 buyers. Tiered packs: Junior $3 (roadmap, Figma mockups, courses), **PRO $4.99** (all 300 components, lifetime), **Premium $8** (adds private components, Vite template, Awwwards portfolio site, VS Code config/extensions, 63 Figma mockups, interview questions, community).
- **Design language:** Pure "wow layer": the effects showcased on award-winning agency/portfolio sites — cinematic scroll choreography, WebGL shaders, magnetic hovers, physics playfulness. No product-UI components at all; it is an effects catalog.
- **Component catalog highlights:** Scroll Animations (71), Sliders (25), Hero Animations (24), 3D Animations (23), Navigation Menus (21), Hover Effects (21), Mouse Effects (21), WebGL Shaders (19), Text Animations (18), Page Transitions (14), SVG Animations (11), Background Animations (10), Grid Animations (10), Physics Effects (10).
- **Install / integration:** Access after one-time payment; components are **code, not prompts** (per FAQ). Landing page does not fully disclose the exact stack/languages — FAQ asks "what languages are these components built with?" without exposing answers in static HTML; treat stack as unverified. No registry/MCP/CLI — download and integrate manually.
- **Stack & dependencies:** Not officially disclosed on the landing page (unclear vanilla JS vs. GSAP/three.js per component); no framework claimed — use with care and inspect code before adopting. Not open source; redistribution prohibited by terms.
- **Skills to steal:** (1) The category taxonomy is itself a checklist of motion archetypes (scroll, mouse, page transitions, physics, shaders) — useful as a "motion coverage map" when auditing any site; (2) extreme price anchoring (one coffee vs. 10,000 hours saved) and tiered pack upsell; (3) proof that Awwwards-style effects can be productized — the *techniques* (scroll-driven timelines, WebGL displacement, cursor-reactive fields) are the transferable asset, not the files.

### 21st.dev — https://21st.dev
- **What it is:** A **community registry / marketplace of 12,000+ hand-crafted React + Tailwind CSS components, full templates, shadcn themes, shaders, and gradients** published by real design engineers. Not a library — a multi-author registry ("many authors, many takes on the same problem"). Anyone can publish; authors keep attribution and can sell templates.
- **Design language:** Deliberately plural — "ten hero sections that look nothing alike, twenty pricing tables, buttons that were designed, not generated." Positioning: start from real human-designed UI instead of the "bland AI average."
- **Component catalog highlights:** Marketing blocks (heroes, pricing, testimonials) and UI primitives (buttons, inputs, dialogs); full multi-page templates; shadcn themes; shaders and gradients; component libraries page aggregating third-party registries; 21st AI for generating/refining UI.
- **Install / integration:** Three ways: (1) **shadcn registry format** — `npx @21st-dev/cli@latest init --client <cursor|claude|codex|vscode|devin>`; (2) classic shadcn CLI install command per component; (3) **Copy Prompt** — an AI-ready prompt that makes Cursor/Claude Code/v0/Lovable rebuild the component wired to your stack (the most common path per their FAQ). Agent infra: `.md` twins for every supported page, `llms.txt`, OpenAPI 3.0 spec, API catalog (RFC 9727), resource manifest, agent skills index.
- **Stack & dependencies:** React + TypeScript, Tailwind CSS, composes with shadcn/ui primitives and your design tokens; works with Next.js, Vite, Remix, Astro. Free browsing + **2 free component copies/day**; membership unlocks unlimited copies + premium templates; 21st AI is a credit-based add-on.
- **Skills to steal:** (1) "Copy Prompt" as an install method — treat the AI agent as the primary runtime and the CLI as the fallback; (2) registry-not-package philosophy (code lands in your repo, no version to upgrade, no lock-in); (3) `.md` twins + OpenAPI + skills index — the most complete machine-readable surface of any site in this research; (4) multi-author aesthetic diversity as an explicit counter to AI-average slop; (5) marketplace mechanics that let template authors sell — community flywheel.

## Category Synthesis

**How part-2 libraries complement part-1 (shadcn/ui, HeroUI, Aceternity):**
- **shadcn/ui (part 1) is the foundation layer**: accessible headless primitives + design tokens. Everything in part 2 either *extends* it (SmoothUI, cult-ui, 21st.dev, React Bits all install through the shadcn registry protocol) or *coexists* with it (HyperUI, Preline, PrebuiltUI are copy-paste markup that can sit inside a shadcn project without conflict).
- **HeroUI (part 1) covers polished product UI** — part 2 adds what it lacks: SmoothUI adds spring-physics motion primitives with reduced-motion discipline; Preline adds enormous block/template breadth and a Figma system; React Bits adds expressive showpieces.
- **Aceternity (part 1) is hero-section flair** — React Bits is its broader, deeper successor: 63 interactive backgrounds vs. a handful of effects, 4 code variants, sound, and creative tools; Animmaster is the paid one-file version of the same idea; 21st.dev supplies aesthetic *diversity* that no single-author library can.
- **New capability axes part 2 introduces:** sound design (React Bits Sound Lab), device mockups as components (cult-ui), animated icon system in pure SVG+CSS (Preline), AI-agent blocks (cult-ui's AI SDK Agents, React Bits micro-interactions), and multi-author marketplaces (21st.dev).

**Decision guide by project type:**
- **SaaS product / dashboard (React):** shadcn/ui base + Preline or HyperUI application blocks; SmoothUI for motion primitives; React Bits micro-interactions for AI-chat UX (Prompt Bar, Call Chip, Status Mark).
- **Marketing landing page:** HyperUI marketing + Preline blocks for fast structure; React Bits backgrounds/text animations (or Aceternity from part 1) for the hero; PrebuiltUI when a full vertical template is faster than assembling.
- **Portfolio / creative / agency "wow" site:** React Bits (backgrounds, galleries, cursor effects, page-level animation wrappers) + Animmaster techniques (scroll choreography, WebGL shaders, page transitions) on a Vite/Next base.
- **E-commerce:** Preline (Storefront 39-page template, checkout flows, product grids) or HyperUI carts/cards; PrebuiltUI Maison template for luxury retail.
- **Non-React or multi-framework stack (HTML, Vue, Rails, Django, Laravel):** HyperUI or Preline first (HTML/Tailwind markup, no React required); PrebuiltUI HTML variants as a fallback.
- **AI-agent-built UI (Cursor, Claude Code, v0):** 21st.dev (Copy Prompt + MCP + OpenAPI) and SmoothUI (MCP + public API) as the discovery layer; React Bits `@react-bits` registry via shadcn MCP for animated pieces; Preline MCP/AI Prompts for block-level enterprise builds.
- **Fastest safe default:** if the project is React + shadcn, combine shadcn/ui (structure) + SmoothUI (primitives with motion + a11y) + React Bits (memorable moments + sound), and pull one-off sections from 21st.dev/HyperUI rather than installing another dependency.
